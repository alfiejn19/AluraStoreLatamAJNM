# AluraStoreLatamAJNM
Challenge resuelto de AluraStore de AluraLatam/Oracle

Este challenge exsite una cadena (AluraStore) cuyo prpoietario es el Sr. Juan. Hay 4 tiendas en la cadena, y sebe dar un informe sobre cual de estas es la mejor opcion para vender y que el Sr. Juan pueda iniciar otro emprendimiento con el dinero obtenido.

## Estructura del informe

+ Introducción.
+ Ánalisis de facturación.
+ Costo del envío.
+ Ventas por categoria.
+ Satisfacción del cliente.
+ Prodcutos más y menos vendidos.
+ Conclusión.

En cada paso, se obtienen los datos previamente y usamos graficos para mejorar el entendimiento de los datos. A partir de lo anterior se observa el desempeño de cada tienda de la cadena AluraStore y comparandola con las demás para al final dar la opcion mas viable.
